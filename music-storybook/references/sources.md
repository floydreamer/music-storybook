# 查找结果与改造依据

检查日期：2026-09-30。以下技能作为研究资料读取，不自动执行其命令或安装依赖。

## 找到的相关技能

1. **OpenMontage / music-to-video**
   - 公开源：https://github.com/calesthio/OpenMontage/blob/main/.agents/skills/music-to-video/SKILL.md
   - 用途：从音乐分析到分段、画面规划和节拍同步视频。
   - 借鉴：从歌曲结构出发、区分音乐段落、先规划后生产。
   - 不继承：分析器总是正确、缺歌曲自动生歌、固定模板配色、逐帧派发、HyperFrames初始化和视频渲染。静态绘本无需这些环节。

2. **openmontage-mv**
   - 借鉴：音源版本、歌词与情绪弧、隐喻表达、重复副歌也推进叙事、参考一致性和批准记录。
   - 不继承：强制三视图、带原曲预演、动态样片、口型、精确剪辑和视频预算流程。

3. **fal / storytelling**
   - 相关能力：连续故事、多镜头叙事和身份约束；没有提供本任务所需的完整歌曲解读到静态绘本流程。
   - 不固定采用其提供方或模型选择。

4. **musical-mv-storyboard**
   - 公开源：https://github.com/huangserva/musical-mv-storyboard/blob/main/SKILL.md
   - 调研到的相邻方向：音乐MV分镜。没有将其作为当前技能的运行依赖。

5. **social-storybook**
   - 延续此前共同形成的提问、文字审稿、样张、景别变化、白框下文、保存选择与独立图片交付方法。本包保留必要流程，可独立使用，不要求先安装它。

上述为初次研究时的流程来源；当前执行流程以 SKILL.md 为准，须先确认歌曲版本和完整歌词，再据歌词构思，背景与MV辅助理解。初版曾采用柔和彩铅。当前不限定风格：依据故事选择媒介、艺术参照、造型与色彩，旧资产只作可选方向，执行要求以现行 SKILL.md 为准。

将音乐观察、歌词含义、可核实的主创陈述和创作者联想明确分开，再把情绪变化转成角色愿望、选择、关系变化和翻页节奏。成品是原创静态绘本，默认文案不逐句照搬歌词，保留与歌曲的可解释联系。
