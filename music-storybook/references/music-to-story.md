# 音乐到故事：理解与转译

## 先取得完整歌词并确认版本

对有词歌曲，先完成以下核对，再构思故事：

1. 确定歌名、演唱者与用户要用的版本；录音室、现场和翻唱可能删改歌词。以实际版本为准，不能凭歌曲时长推断文本完整。
2. 优先读取官方/正规音乐平台的完整歌词或用户提供的歌词。检查首尾、主歌、副歌、桥段及重复段落的覆盖；不强迫每首歌都有桥段。搜索引擎摘要、截断网页、只有副歌的内容均不算完整。重复段落可标重复，但不能遗漏变词或不同结尾。
3. 页面不全、版本冲突、听不清、自动转写有重要不确定字词时，标明缺失位置，请用户粘贴完整歌词或提供音乐链接。用可用工具读取链接关联的歌词/字幕；音乐流不一定附带可提取歌词，转写也只是待核对材料。不要绕过登录限制，不承诺任意平台都能提取。
4. 简要呈现版本、来源链接、是否完整以及分段含义，请用户确认作为创作依据；不把搜得的完整歌词原文复制进答复或成品。用户已明确提供完整文本或批准同一版本时，记录已有确认，避免再问一次。
5. 未完成这一关，只可继续资料搜集和询问，不能用主创故事或用户感受先代写情节。用户后来明确改为“仅据已提供片段创作”时，尊重新的范围，标注为片段启发而非完整歌曲改编。

纯音乐须先确认无歌词，然后使用实际听音或用户描述作为明确例外；缺少歌词资料不等于纯音乐。

## 歌词确认后，搜集辅助背景

辨认曲目和版本后，开展跨来源网络搜索；不只搜索歌名一次就声称没有背景故事。可组合歌曲原名、演唱者、词曲作者，以及“创作背景 / 访谈 / 专辑说明 / 歌词 / 官方MV / 导演阐述”，必要时用原语言搜索。优先官方发布、本人访谈和署名报道，打开与结论直接相关的页面；聚合简介和搜索摘要只作线索。

搜集三类内容，并分别保留出处：

1. **创作背景与表达**：何时、因何创作，主创明确表达了什么；区分作词、作曲、演唱和MV导演的说法。版本不同可能改变语境，不把别的版本的解释直接套用。
2. **歌词的故事**：谁在说、对谁说，发生了什么，什么在变化；含混处保留多义。歌词只提供意象或感受时，明确叙事情节需要原创。
3. **官方MV的故事**：角色关系、关键行为、视觉母题和结尾。能实际查看画面或可靠逐段内容时才描述具体情节；只有简介则注明“据官方简介”，只有链接、标题或封面不能声称看过完整MV。没有MV不影响创作。

以辅助资料是否足以解释必要语境为停止条件，不追求穷尽全网。创作背景找不到，不影响依据已确认完整歌词推进；歌词还不完整，则用户共创也不能替代补齐。网络不可用与“网上没有资料”是两回事。私有歌曲、用户不允许联网时，直接使用用户材料并说明范围。

记录：来源标题、作者/发布主体、日期（可得时）、链接、支持的结论、事实/主创自述/二手描述/个人解读。不要把多个转载当作多份独立证据；冲突尚未解决的材料不作为确定事实。

## 歌词已确认、背景不足或含义多解时的互动

先给一句准确的现状，例如“歌词能看出一种未说出口的告别，但没有找到主创说明”。问题围绕当前缺口，不每次机械问完所有项目：

- **情感入口**：你听这首歌时最先想起什么场景？希望读者最后感到安慰、遗憾、自由，还是别的？
- **关系与愿望**：故事中的主角最想为谁做一件什么事？这件事为什么一直没完成？
- **变化与余味**：发生什么小事会让主角改变？最后希望得到回应，还是学会带着未完成继续生活？

每轮问1–3个最关键问题，允许用户只回答其中一项；基于回答给具体构想，再补剩余关键缺口。用户没有现成故事时，提供少量不同方向帮助想象，不要求用户完成编剧工作。不要擅自把虚构写成用户亲历。

输出完整故事供确认，尚未确认时可以讲关键画面意象，但不抢先生成整套图片。确认稿交代人物关系、愿望、阻力、因果连接、转折和余味；删掉资料来源后仍应是一篇能独立读懂的故事。丰富来自关系和选择，不来自堆叠幻想设定。

## 输入分支

| 已有材料 | 可立即做 | 不能声称 |
|---|---|---|
| 音频 + 歌词 | 核对版本、分析乐句与文本，形成情绪图 | 自动转写必然准确、歌词一定是自传 |
| 只有音频 | 有工具则试听/转写，核对完整性及存疑字词；确认无歌词才走纯音乐分支 | 未听清的歌词是原文、某种音色对应唯一情绪 |
| 只有歌词 | 核对版本、全文范围后分析叙述、意象、关系；可做歌词驱动方案 | 已听过旋律、BPM或精确段落秒数 |
| 歌名或链接 | 定位版本并尝试获取完整歌词；失败时请用户粘贴 | 搜索摘要等于已获得全文或已听完歌曲 |
| 主创或听者的自述 | 收集偏好与辅助背景，同时补齐歌词 | 自述足以跳过歌词、听者感受代表主创原意 |

播放地址不可访问时可请用户提供音频或歌词；上传文件用普通消息提问，不放进仅支持文字回答的问答工具。不要要求凭证、绕过访问限制，或自动订阅服务。

## 歌曲理解卡

```text
曲目 / 演唱者 / 版本：
完整歌词核对：来源、实际可读范围、分段、重复变词、存疑项
确认状态：已由用户提供/确认的版本；尚待补充或确认的内容
材料：音频、歌词、用户自述、公开来源，各自实际可访问状态
听音/转写状态：工具与范围；未验证项
叙述视角与关系对象：明确内容 / 可有多解之处
核心矛盾：想得到什么，什么阻挡或缺席
情绪变化：起点 → 转折 → 高点 → 余韵
意象及其意义变化：最多3–5个，不做所有名词的清单
主创陈述：来源、日期、支持的具体结论；没有则未知
官方MV：实际查看范围 / 简介来源；角色关系与事件；与歌词的异同
用户希望保留：
本次改编解释：与事实分开
```

先看完整语境：同样的“回去”可能是归家、回忆、拒绝离开或无法回返。旋律明亮而歌词失落时，保留这种张力，不把高能量误解成快乐。主歌/副歌/桥段以实际材料为准，不给所有歌曲套同一结构。

可选情绪映射：

| 段落/已验证区间 | 歌词含义（概述） | 音乐观察或用户描述 | 情绪变化 | 叙事转译 | 依据/不确定性 |
|---|---|---|---|---|---|
| 第一段；秒数未知 | 某种等待 | 仅有歌词，未试听 | 克制、期待 | 主角为未出现的同行者留下位置 | 歌词解读；对象待确认 |

只需对故事有效的粒度；不强制 BPM、调性检测、逐字时间轴或完整节拍图。若调用现有音乐分析器，先确认位置与依赖，保留自动结果与人工解释，分析器输出不能直接当情感真值。

## 完整歌词的深读与故事编辑

歌词完整不等于已经理解。写故事前给出简短的深读结果：

- **语义与视角**：谁对谁说、何时在说、明确事实与含混处；别把歌词中的“你”自动解释成前任或逝者。
- **情感张力**：并存的愿望与矛盾、说出口与留下没说的内容、否定词或语气中的变化。不要把复杂感受压成“失恋后治愈”等标签。
- **全曲推进**：重复句前后的语境、细微变词、结尾未完成之处。关键句要置于全文解释，不把喜欢、失去等单词单独变成剧情命令。
- **可画的关系**：从动作、空间、距离、时间变化与物件使用中，提出可以承载核心命题的场景；至少说清关键场景怎样同时表达矛盾的两面。

采用世界顶级短篇故事创作者的工作标准：先形成少量不同结构，再审视开篇的阅读欲望、人物愿望与阻力、起承转合的因果和结尾的回响。向用户交付提案、简明依据与具体故事；无需暴露内部推演或给出虚构的反复思考次数。

创意编辑重点：

- 钩子提出一个具体问题，故事中有兑现；避免谜语式悬念、夸大悲剧或先把结局说完。
- 想象设定若存在，须在中段或结尾改变人物行动、限制或认知，不能只作为通往普通恋爱情节的装饰入口。
- 不用死亡、意外、奇迹重逢或道理式独白替代自然的张力；也不机械禁止普通生活，独特性可以来自观看角度、关系中的错位和图文之间的余意。
- 细节应有作用：揭示性格、改变关系、建立后续回响或让读者重新理解前文。会被忘记的细节也可有价值，但不能只是堆道具。
- 结尾允许仍有喜欢、仍有遗憾、仍不知道；不自动安排收到回复或团圆来证明情感成立。结尾的开放度遵循歌词与用户选择，不把某一首歌的结局推广为模板。
- 用“换一首歌是否仍完全适用”“幻想设定删掉是否毫无影响”“中段是否只剩同表情散步”“最后一页是否只在总结道理”审稿；有问题就改相关段落，不为标新立异添加无关事件。

每个故事按11–17张含封面组织：先列必要转折、微小互动与情绪停顿，再确定页数。关键互动需要几页就给几页，其余可合并；超限时精简结构，不把完整故事硬切成固定数量。

## 原创叙事的桥梁

1. **提炼一个情感命题**：例如“仍在等，却开始向前走”。它不能泛化到任何歌曲；说明来自哪一层歌词或情绪变化。
2. **选择承载者**：人物、动物或物件，应适合歌曲视角。叙述者身份不明确时，角色可虚构，不将歌手肖像默认放入绘本。
3. **创造可画的愿望**：抽象的“被理解”变成一个角色希望另一方完成的具体动作。
4. **选择合适的叙事方式**：日常写实、内心独白、双时空或意象组诗都可成立。需要幻想时再建立少量一致的规则，不把歌词比喻强行变成真实世界的奇迹。艺术感也来自构图、笔触、留白与翻页。
5. **通过选择推进**：每页发生一个发现、决定或关系变化，不能九页都在不同风景中走路。
6. **让意象复现而改变**：开始挡住视线的窗，后来可以让光穿过；这种呼应不是把同一构图无意义重复。
7. **给结尾留下余音**：可以安顿，也可以未解；不为社交媒体文案强行加祝福或励志口号。

以上示例只解释创作方法，不是默认角色、场景或结局。每首歌应有适合它的叙事承载者；使用幻想时再明确其规则。

## 歌词与背景的使用

默认输出原创短文案和歌词含义概述；不要搜来完整歌词逐页贴上，或用连续的近似改写替代原歌词。用户提供的歌词可以在其请求范围内处理，但成品仍优先独立叙事。确需引用时遵守适用版权限制；注明来源并不等于已获得使用许可。

有主创一手材料时，将有依据的陈述和改编虚构分别记录。缺少可靠背景但歌词完整且已确认时，仍可据歌词创作，明确这是我们的解读，不把推断冠以“主创真正想表达的是”。缺少完整歌词时先补齐材料。
