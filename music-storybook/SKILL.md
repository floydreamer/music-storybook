# 音乐绘本

让歌词成为情节依据，让音乐的变化帮助组织情绪与翻页节奏。成品即使没有音乐也能读懂；听着选定版本再看时，能辨认歌词与画面之间的呼应，并从具体生活片段中投射自己的经历。

本技能由已检查的 OpenMontage 音乐叙事方法与 social-storybook 图文流程改造，来源及取舍见 [参考来源](references/sources.md)。这是独立静态绘本流程，不执行原视频技能的初始化、强制三视图、逐拍切镜或视频渲染。

## 1. 必须先确认完整歌词，再构思故事

告知用户正在使用音乐绘本技能。读取既有项目与已确认选择，从当前阶段继续。新项目先辨认歌名、演唱者、录音室/现场/翻唱等版本，获取并核对该版本的完整歌词。向用户简要确认选用的版本与歌词来源；用户已经明确提供或确认同一份完整歌词时，不重复询问。

**新项目启动时先开展艺术家检索，不等出图后再补参考。** 根据用户的风格偏好与歌曲初步情绪，检索3–5位相关插画或绘本艺术家的实际作品，读取 [艺术家检索与综合创作](references/artist-research.md)。歌词研究与艺术调研可并行；故事确定后再筛选、综合绘画方法，形成统一的原创视觉语言，随后设计详细画面。续作沿用已核实的研究，风格改变时补充检索；用户明确不联网时使用其提供的资料并说明限制。

**歌词是有词歌曲构思的前置条件。** 搜索摘要、短视频片段、副歌节选、歌词解说、MV剧情、主创访谈或听者感受，都不能替代完整歌词。没有核实完整性，或重要字词、段落有疑问时，不先编故事或出图；请用户粘贴完整歌词，或提供能访问歌词的音乐链接。链接只能作为提取入口，不能保证所有平台都可读取；提取失败则说明缺口并请用户粘贴。禁止按记忆、网络概述或自动转写猜补。

完整性与版本核对方法见 [音乐到故事](references/music-to-story.md)。找到歌词后，以来源链接、段落结构与含义摘要供核对，不为确认而把网络获取的受版权保护歌词全文贴回。确认为无歌词的纯音乐时，记录这一事实，再用实际听感和用户感受建立另一条明确标注的创作依据。

## 2. 歌词优先，背景与MV辅助理解

完整歌词确认后，按全文语境理解叙述者、关系对象、动作、意象与情绪转折，再跨来源搜索歌曲背景、主创表达及官方 MV 的情节；歌词核对期间可并行搜集这些辅助材料，但不提前定故事。优先主创访谈、官方发行说明和官方 MV。区分歌词、歌曲创作背景与 MV 导演另写的故事，记录来源和未知项。背景帮助理解，不能覆盖歌词的叙事矛盾；歌词未明确的关系或结局，标为本次改编选择。用户不希望联网或歌曲未公开时，使用其提供的材料，不上传私有音源进行公开搜索。

整理简短的“歌曲理解卡”：版本与可用材料、歌词叙述者和对象、核心愿望/矛盾、情绪弧、反复意象、MV 情节、主创陈述来源、我们的改编推想。给用户看与故事有关的发现，不倾倒搜索记录。

- 能实际访问并分析音频才报告音乐听感、段落或时间；只有歌词时明确“歌词层面的解读”，音乐段落时间标记未知。
- 有可用工具时分析完整段落、疏密、张力和停顿。响度、BPM或调性不能单独证明情绪，更不能证明主创本意。
- 用户作为主创的自述是本次创作方向；公开歌曲的创作背景优先查主创采访、官方发布或专辑说明，记录直接支持该说法的链接。找不到就留未知，不拿歌迷猜测当事实。
- 歌词第一人称不等于歌手本人；失去不必等于死亡，等待不必等于爱情。不要擅自替歌曲补一段真实传记。
- 没有歌词的纯音乐仍可改编，以音乐变化和用户描述构建故事，明确这是原创联想。

不需要为了静态绘本搭建音频工程。无法听音但完整歌词已确认时，可以做歌词驱动方案，注明尚未验证音乐段落与听音节奏；有词歌曲仅有感受或背景时仍须先补齐歌词，不替用户生歌。

## 3. 以短篇故事创作者的标准构思与修订

承担世界顶级短篇故事创作者的创作职责，把这一定位落实为可检查的故事质量，不用“大师级”标签替代设计。先深读完整歌词，再写故事：辨别说了什么与留下什么、矛盾和转折、重复段落的变词及含义变化；记录核心命题与至少一个不能被泛化的情感张力。具体方法见 [音乐到故事](references/music-to-story.md)。不能只抓副歌、歌名或背景事件。

构思与审稿至少分别检查歌词忠实度、故事因果和新鲜度：开篇让读者产生一个具体疑问，中段让人物经历选择、阻力或认识变化，高潮使开篇设定真正作用于关系，结尾回应或重释前文。张力可以来自迟疑、误解、有限时间和未出口的话，不强制灾难、反转或强情节。情绪组诗也要有可辨认的推进。

避免有趣的设定过后只剩泛用恋爱或散步蒙太奇。幻想入口应影响后续行动、代价或结尾；新奇细节应服务关系，不能堆砌噱头。用“换成另一首歌、换掉角色后是否仍完全成立”“删掉这一页是否不影响任何发现”检查并修订。展示提案与关键取舍，不输出冗长内部推演，也不编造多轮评审经历。

默认根据已确认歌词给2–3个真正不同的短提案，再展开选定方向；用户明确了方向就直接深化。提案各自说明：对应的歌词段落含义、读者代入点、角色关系、开篇引子、关键变化和结尾余味，以及新增的虚构内容。差异应来自叙事视角和结构，不只是换角色名字或地点。可选方法见 [伴听卡片的叙事设计](references/listening-cards.md)。不要把歌词机械拆成事件清单，也不逐帧复刻MV。

完整歌词已确认，但背景缺失或叙述有多义时，通过提问共同创造。每轮1–3个问题，优先问“哪一段歌词最像你心里的话”“它让你想起谁或哪件小事”“结尾希望留下什么感受”。提供少量方向帮助表达，再补人物愿望和转折。用户自述是选取解读视角的依据，不替代歌词；自由创作授权也不意味着可以跳过完整歌词核对。

交付供确认的**完整故事**：题目、情感核心、角色与关系、具体愿望、幻想规则（如有）、起因—行动—转折—结尾，以及与歌曲的联系。故事需讲清情感对象与行动因果，包含能被画出来的发现和变化；不能只交一句概念或一组情绪词。详细方法见 [音乐到故事](references/music-to-story.md)。

故事至少有可理解的愿望、行动与变化。重复副歌可让同一意象改变意义；间奏可化为无言发现或留白。高潮可是一只手终于松开，不必总是大场景。结尾回应原曲的开放/释然/遗憾等实际气质，不强行圆满。

默认先确认完整故事，再进入逐页视觉设计；随后确认图文分镜，再出图。已有明确授权则沿用，用户要求直接完成时可合并环节；没有回复不视为批准。用户只要文字，就交付到文字层级。

## 4. 将关键情节设计成有区分度、可伴听的图文

故事确认后，读 [视觉与分镜](references/visual-storyboard.md)，生成含封面的详细图文分镜表。默认总数为 **11–17 张，包含封面**，依情节、情感停顿和翻页节奏决定具体张数；不固定为某一数量，不用重复场面凑数。用户另有明确页数要求时按其要求执行。所有成品的完整画布统一为竖版 **9:16**。第一页为全画面封面，不留底部白色文字区；其余页由插画、白框和下方留白文案共同组成 9:16，不能给一张 9:16 插画再向外追加文字区。根据故事节奏分配页数，而非凑齐固定数量。尚未明确的读者、结尾倾向、必须保留/避免的内容和呈现偏好，在影响设计时简短询问，不重复已知选择。

封面画面内安排一句原创的**故事钩子**，让读者想知道后续，同时不泄露结局；其下依次放歌曲名、演唱者及词曲作者的明确署名。核实选定版本的署名，不把歌手默认当作词曲作者。封面钩子、署名和排版位置一并纳入分镜审阅；详细层级见 [视觉与分镜](references/visual-storyboard.md)。

建立逐页“歌词段落/含义 → 心理或关系变化 → 具体画面动作 → 原创文案 → 翻页理由”的对应表；过渡页和封面也说明承接哪个歌词主题。有词歌曲不能只写“孤独、治愈”这样的泛化标签。不是逐句配图，也不要求每句歌词都有一页，但应保留全曲核心矛盾和关键转折。

设计可跟随主歌、副歌、间奏等已核实段落的阅读路径：关键画面与情感高点呼应，安静页给读者停留，同一副歌再次出现时让同一物件或动作获得新意义。静态卡片由读者自由翻页，默认提供段落提示而非强制秒数；没有实际音源/时间戳依据，不虚构精准同步。具体方法见 [伴听卡片的叙事设计](references/listening-cards.md)。

让远景、中景、近景、细节及必要的无人画面各有作用，同时变化场景、视点、人物占比、视觉重心与留白。不能只换背景连续画同样大小的人物。每页既有独立美感，又推进发现、选择或关系。以顶级绘本创作者的标准逐页设计：明确唯一情感瞬间、表情与身体动作、画内关系、视觉重心、线条/笔触节奏和翻页作用。人物身份一致不等于表情、姿势一致；同场角色也有不同反应。允许背影、局部和无人页承担情绪，不为差异强加夸张表情。详见 [视觉与分镜](references/visual-storyboard.md)。

正文页下方默认一两句**原创叙事文案**，避免逐句翻译歌词。图画说动作与空间，文字说迟疑、关系与发现，指代清晰。只改用户点名的句子，其他已确认文案逐字保留。

## 5. 确定画风，先样张后整组

此阶段将启动时的艺术家研究与已确认故事汇合：给出作品来源及各自借鉴的具体方法，说明怎样统一、舍弃哪些不合适的部分。没有实际查看作品，不能声称已完成风格研究。不要仅凭记忆列名家或把几位名字串成生图提示词。

**不预设媒介、色彩、抽象程度或艺术流派。** 根据歌词情绪、故事结构、时空、角色和读者体验，选择适合的世界优秀绘画、绘本、插画及艺术家作品作为研究参照。彩铅、粉彩只是可选媒介，也可采用炭笔、水墨、版画、拼贴、油画或混合材料等。用户已有风格选择时承接，不因本技能默认探索而推翻。

没有选定方向时，提出2–3个视觉逻辑真正不同的方向，说明为何适合故事、借鉴哪些具体绘画方法及其取舍。提到具体艺术家、作品或传统时核实参考，使用实际可查看的作品和可靠来源；不以名气排序，不虚构看过作品，也不承诺创作者背书。把参考转成媒介、线条、构图、色彩、造型与虚实关系的可执行描述，不只堆艺术家名字，不照搬既有作品的独特构图和角色。

每页均可按叙事选择绘画方法，但整组需有主导视觉语言、角色识别和色彩关系。记忆/当下、情绪转折等可有理由地变化媒介或线条，提前规划并解释；不默认每页随机模仿一个艺术家。艺术性来自取舍、节奏、形与空间，而非统一颗粒滤镜、杂乱线条或处处精修。

线条与笔触应有轻重、快慢、断续、疏密和虚实，随具体动作与情绪组织。画面灵动不等于所有头发、树木都被大风吹乱。表情、视线、头部倾角、手势、肩背重心共同表达情绪，不批量复制同一微笑。完整方法见 [视觉与分镜](references/visual-storyboard.md)。

封面文字融入画面安静区域，可有轻柔手写感，但钩子和署名均须清晰可读。正文页保留薄白色上/侧框及较宽的底部文字区，使用有仿宋气质、笔画不至于消失的较大字号。以手机宽度预览、无需放大即可阅读为验收条件；字号与留白起点见 [制作与恢复](references/production.md)。

既有已选样张适用时直接复用；否则先生成代表性样张，检验所选画风、人物表现、场景与排字；一种画风用一张起步，跨时空或媒介变化需要对照时可用2–3张，用户要求风格探索时按其范围执行。方案与样张确认后连续完成其余独立图片。不要用拼图替代独立成品页，不默认制作视频或额外封面候选。

## 6. 生成、校验与保存

开始整组生成前，从已选样张明确角色服装、参考图职责与同场空间关系；身份一致不等于姿态一致。遇到重复场景、照片/画中画、换图或调序时，读取 [连续性与修订](references/continuity-and-revision.md)，用稳定来源编号维护跨页引用，检查原场景变更对后续页的影响。局部修改以用户认可版本为基础，不重新设计整本。

按 [制作与恢复](references/production.md) 执行。优先当前内置图像生成工具；如有 imagegen 技能则读取其说明。只有用户指定其他提供方才按对应技能执行，不因“高画质”擅自改用另收费API。

每页提示词包含：整组视觉约束与角色、此页绘画方法、唯一动作瞬间及具体表情/身体状态、视点景别与构图、笔触与边缘、光色、物件关系、精确文案、参考图职责。逐页检查汉字和版式，再检查整组的景别、情感递进、人物身份与物件尺度；同时检查有无同表情、同姿势、同构图和无叙事意义的笔触铺满。

保存来源、解读、故事表、实际提示词、用户选定版本和图片，防止只留在临时对话。交付独立图片、完整预览和发布包，报告实际像素与已知限制。发布文案可说明“受这首歌启发的原创绘本”，不冒称主创授权或官方解读；不自动发布到外部账号。
