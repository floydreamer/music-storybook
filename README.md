# Music Storybook · 音乐绘本

从完整歌词、歌曲背景与艺术家作品研究出发，创作有情感推进的原创绘本。

## 工作流程

确认歌曲版本与完整歌词，同时检索相关插画/绘本艺术家的真实作品；故事确认后综合视觉方向，设计11–17张含封面的9:16图文，先样张再整组。支持跨页人物、服装、场景及照片引用的连续性检查和局部修订。

## 安装与使用

把本仓库的 `music-storybook` 文件夹复制到你的 Codex 技能目录（通常为 `~/.codex/skills/`）。在能发现该技能的会话中输入：

> 使用 $music-storybook，为「歌手／歌曲名／版本」创作绘本。先检索艺术家作品并提出故事方向。

需要可用的联网检索和图像生成能力；本仓库是技能指引，不是独立生图服务，也不附带 API 密钥。GitHub 存储便于安装与复用，不会自动给所有客户端安装技能。

## 内容

- `music-storybook/SKILL.md`：入口与整体流程。
- `music-storybook/references/`：歌词解读、艺术家研究、视觉设计、制作与连续性规则。
- `music-storybook/agents/openai.yaml`：技能显示信息。

不附带私人对话、旧项目图片、歌曲音频或完整歌词。创作成果应说明是受歌曲启发的原创改编，不冒称官方授权。
